Check a public repo for credentials it never meant to publish.

Tripline reads a repository's current files straight from GitHub and checks them against known key formats and high-entropy strings. Nothing is uploaded — the scan runs in this tab.

What this does and doesn't do

Scans

  • Every text file on the repository's default branch, up to 300 KB per file
  • Known credential formats — cloud keys, CI tokens, payment keys, private key blocks, connection strings
  • Unlabeled high-entropy strings that look like secrets even without a known prefix

Doesn't scan

  • Git history — a secret removed in a later commit can still exist in an old one
  • Binary files, lockfiles, or anything over the size limit
  • Private repos, unless you supply a token with read access

Findings are pattern matches, not confirmed leaks. Verify anything flagged before rotating a key, and expect a few false positives from high-entropy detection — it trades precision for not missing the unlabeled cases.

Tripline runs entirely in your browser. Repository contents are fetched from GitHub and never sent anywhere else.
